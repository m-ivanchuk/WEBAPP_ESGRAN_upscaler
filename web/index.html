Апскейл

Укажите папку с исходниками и папку для результата. PNG сохраняет прозрачность. JPEG и видео тоже увеличиваются.

PNG, JPEG и видео (mp4, mov, mkv, webm, avi). Скрытые файлы пропускаются.

Имена файлов сохраняются. Папка не должна лежать внутри исходников.

Масштаб

Прозрачность

Для JPEG и видео альфа-канала нет: настройка действует только на PNG.

Если не хватает памяти, поставьте 256 или 128. 0 быстрее и без швов между кусками.

Папки

Структура папок в результате повторяется.

Только у General v3. 0 оставляет шум, 1 сильнее сглаживает.

Дополнительно

Имеет смысл только на NVIDIA. На Mac остаётся обычная точность fp32.
