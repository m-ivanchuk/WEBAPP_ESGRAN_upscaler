# Локальный апскейл

Простая локальная страница для увеличения картинок и видео через [Real-ESRGAN](https://github.com/xinntao/Real-ESRGAN). Указываете папку с исходниками и папку для результата.

Подходят PNG, JPEG и видео (`mp4`, `mov`, `m4v`, `mkv`, `webm`, `avi`). У PNG прозрачность сохраняется: цвет и альфа обрабатываются отдельно. JPEG записывается снова как JPEG. Видео собирается в MP4 через ffmpeg, звуковая дорожка копируется.

Страница открывается только на этом компьютере (`127.0.0.1`). Файлы никуда не отправляются.

## Запуск

Нужен Python 3.10 или новее. Зависимости ставятся в `.venv` в корне репозитория.

```bash
python3 -m venv .venv
.venv/bin/pip install -U pip
.venv/bin/pip install torch torchvision
.venv/bin/pip install -r requirements.txt
.venv/bin/python web/server.py
```

`torch` ставится до `requirements.txt`: сборке BasicSR он нужен уже на этапе установки.

Откроется [http://127.0.0.1:8765](http://127.0.0.1:8765). Остановка — Control+C в том же терминале.

```bash
.venv/bin/python web/server.py --no-browser   # не открывать браузер
.venv/bin/python web/server.py --port 8766    # если 8765 занят
```

На Mac с Apple Silicon страница сама выбирает MPS. На NVIDIA — CUDA. Иначе расчёт идёт на CPU. Половинная точность fp16 включается только на CUDA.

Для видео в системе должен быть `ffmpeg` (`brew install ffmpeg` на Mac).

Первый запуск выбранной модели скачивает веса в `weights/`.

## Настройки на странице

| Параметр | Зачем |
|---|---|
| Модель | `RealESRGAN_x4plus` — обычные картинки и видео. `RealESRGAN_x2plus` — ровно ×2. `RealESRNet_x4plus` — мягче, меньше выдуманной текстуры. `Anime 6B` — рисунки. `AnimeVideo v3` — лёгкая модель для аниме-видео. `General v3` — компактная модель с шумоподавлением. |
| Масштаб | ×2, ×3 или ×4. Если он не совпадает с сетью, размер добивается ресайзом Lanczos. |
| Прозрачность | «Моделью» — альфа тоже идёт через сеть, края обычно чётче. «Растянуть» — альфа просто увеличивается, это быстрее. |
| Тайл | `0` — файл целиком. `256` или `128` — если не хватает памяти. |
| Подпапки | Та же структура каталогов на выходе. |

Папка результатов не должна лежать внутри папки с исходниками.

Командная обработка без страницы по-прежнему доступна через `inference_realesrgan.py`.
